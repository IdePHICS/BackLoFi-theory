# Synthetic experiment: the deep staircase

This directory is reserved for the code of the synthetic experiment of the
paper (Section "Synthetic setting: the deep staircase"): a Gaussian teacher
with a visible feature block and two hidden blocks whose correlation with the
label is unlocked only by the backward score, and the figure comparing forward
Neural LoFi, the backward correction and gradient descent on it (test MSE and
the overlaps with the visible and the hidden blocks against the sample
exponent).

The code will be added here by its authors. Until then this directory holds no
runnable script; the real-data experiments in the rest of the repository do not
depend on it.
